## 📋 项目简介

基于 Cloudflare Workers 的 Docker 镜像代理加速服务。解决部分地区拉取 Docker 镜像速度慢的问题，通过 Cloudflare 全球边缘网络加速 Docker Hub 等镜像仓库的访问。

## 🧱 技术栈

- **平台**：Cloudflare Workers
- **语言**：JavaScript
- **功能**：反向代理 / 缓存加速
