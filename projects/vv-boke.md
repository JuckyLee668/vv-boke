## 📋 项目简介

基于 VitePress 构建的个人知识库与项目记录站点。以「学，行之，上也」为理念，持续沉淀技术文档与项目记录。

## 🎯 站点内容

- 📝 **文档中心**：Markdown / LaTeX 排版笔记
- 💻 **应用开发**：VitePress、CSS、jQuery、Node.js、HarmonyOS 等笔记
- 🐧 **Linux 运维**：Nginx、Shell、MySQL、Telegram Bot API 编译
- 🛠️ **工具导航**：常用开发工具与效率软件整理
- 🔌 **嵌入式 IoT**：MQTT、STM32、智能家居项目
- 🌟 **项目展示**：GitHub 自建项目汇总
