## 📋 项目简介

基于 ESP8266 的智能自动浇水系统，专为家庭绿植和阳台花园场景设计。支持通过 MQTT 远程控制、定时浇灌策略、土壤湿度监测等功能。

## 🎯 主要功能

- 🌡️ 土壤湿度实时监测
- ⏰ 定时浇灌策略配置
- 📱 远程手动/自动控制
- 📊 浇灌记录与统计
- 🔔 低水位/异常报警
- 🔌 支持离线自动运行

## 🧱 技术栈

| 组件 | 技术 |
|------|------|
| 主控 | ESP8266（NodeMCU） |
| 通信 | MQTT / WiFi |
| 后端 | Python |
| 存储 | 嵌入式配置存储 |

## 📌 适用场景

- 家庭阳台花园自动浇灌
- 室内绿植养护无人值守
- 温室大棚湿度监控
