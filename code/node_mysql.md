# Node + MySQL 示例项目

## 项目位置

- 目录：`code/node_mysql`

## 项目简介

该项目是一个基于 Node.js + MySQL 的后端示例，包含数据库连接、用户模型、路由与脚本化数据操作等内容。

## 关键文件

- `config/database.js`：数据库连接配置
- `models/User.js`：用户模型
- `routes/users.js`：用户相关接口
- `createTables.js`：建表脚本

## 使用建议

1. 在 `code/node_mysql` 下安装依赖并配置 `.env`。
2. 先执行建表脚本，再启动服务进行接口测试。
3. 将稳定实践同步沉淀到本目录文档中。
